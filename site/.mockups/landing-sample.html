RAG & Knowledge Graph

A single Go binary combining hybrid search (BM25 + Vector) with an in-memory knowledge graph. Exposed natively to AI tools via Model Context Protocol (MCP). No Python, no Postgres, no Docker. Just pure performance.

Core Modules

Engineered with strict boundaries and dependency injection.

Hybrid Search Engine

Combines Lexical (FTS5/BM25) and Semantic (vec0/Cosine) search using Reciprocal Rank Fusion (RRF, k=60).

  • › Parallel goroutine execution
  • › Enricher + Reranker pipeline
  • › Freshness & Authority boosts

In-Memory Graph

Loads entire entity graph at startup for O(1) lookups and fast BFS traversal (max depth 10).

  • › Domain-specific XML configs
  • › Fact Review Workflow
  • › Graphviz DOT export

MCP Server

Exposes tools natively to Claude Desktop and Cursor via HTTP/SSE transport. Self-documenting API.

  • › hybrid_search tool
  • › get_entity_relations tool
  • › Graceful shutdown (SIGINT)

Local Embeddings

Pure Go binary using ONNX Runtime. No Python required. INT8 quantized BGE-M3 runs efficiently on CPU.

  • › L2-normalized vectors
  • › In-memory cache shared
  • › OpenAI API fallback

Fact Review Workflow

LLM-extracted facts go through confidence-based validation: Draft → Pending → Approved/Rejected.

  • › Provenance tracking
  • › Auto-publish thresholds
  • › Traceability to chunks

File Watcher

Auto-updates the knowledge base during serve mode using fsnotify. Debounces events to prevent spam.

  • › Recursive directory monitoring
  • › 30s debounce default
  • › Filters .md and .json

Data Flow

From raw files to enriched context for your LLM.

1 Ingestion Pipeline

Parsing & Chunking

Markdown, JSON, HTML, MediaWiki. Header-based or fixed-size chunking with overlap.

Embeddings & Storage

ONNX generates vectors -> stored in vec0. Text stored in chunks + FTS5 sync triggers.

NER & Graph Construction

Prose or LLM extracts entities. Deduplication links them to chunks and builds relations.

Fact Extraction & Provenance

Structured facts extracted, assigned confidence scores, and routed through review workflow.

2 Query Execution

Parallel Search

MCP Client calls hybrid_search. FTS5 (BM25) and vec0 (KNN) run concurrently.

RRF Fusion & Enrichment

Reciprocal Rank Fusion merges lists. Enricher attaches document metadata and associated entities.

Business Rule Reranking

Deprecation penalties, authority boosts (policies x1.5), and freshness boosts (90 days).

Graph Expansion

BFS traversal on result entities attaches related edges and approved facts to the context.

Technology Decisions

Why we chose specific tools over mainstream alternatives.

SQLite over PostgreSQL

Zero Infrastructure
No separate DB server to manage. FTS5 and sqlite-vec (vec0) are built-in. WAL mode supports concurrent reads during ingestion, which is more than sufficient for documentation scale (tens of thousands of chunks).

ONNX Runtime over Hugging Face

Pure Go Binary
No Python dependency. INT8 quantized BGE-M3 runs efficiently on CPU (~1024-dim vectors). Fully offline operation with no API keys required. Falls back to OpenAI-compatible API if needed.

RRF over Weighted Scoring

Reciprocal Rank Fusion
No need to normalize different score scales (BM25 vs Cosine distance). Items appearing in both lists naturally rise to the top. Single tunable parameter (k=60) proven effective per Craswell et al., TREC 2021.

MCP over REST/GraphQL

Model Context Protocol
Native integration with Claude Desktop and Cursor. Tool schema is declarative and self-documenting. Designed specifically for LLM agent consumption rather than human browsing via standard HTTP/SSE.
